# Quellenkontor SDKs und CLI

Offizielle Clients für die [Quellenkontor](https://quellenkontor.dev)-API: geprüfte HR-Daten für Deutschland mit Quelle, Rechtsgrundlage und Gültigkeit.

**English:** Official clients for the [Quellenkontor](https://quellenkontor.dev/en) API, verified German HR reference data with source, legal basis and effective date. English docs at [quellenkontor.dev/en/docs](https://quellenkontor.dev/en/docs).

| Paket | Installation | Doku |
|---|---|---|
| [JavaScript/TypeScript SDK](packages/sdk-js) | `npm install @quellenkontor/sdk` | [quellenkontor.dev/docs/sdk-javascript](https://quellenkontor.dev/docs/sdk-javascript) |
| [Python SDK](packages/sdk-python) | `pip install quellenkontor` | [quellenkontor.dev/docs/sdk-python](https://quellenkontor.dev/docs/sdk-python) |
| [CLI](packages/cli) | `npm install -g @quellenkontor/cli` | [quellenkontor.dev/docs/cli](https://quellenkontor.dev/docs/cli) |

Einen kostenlosen Schlüssel gibt es unter [quellenkontor.dev/anmelden](https://quellenkontor.dev/anmelden). Fehler und Wünsche gern als [Issue](https://github.com/NicksAdvisory/quellenkontor-sdk/issues) oder an hello@quellenkontor.dev.
